# Bilingual writing

First identify audience, purpose, language, and mode. Default to **research** for methods, findings, applications, and portfolio claims; use **literary** when the user wants narrative cadence or expressive writing. Preserve the author's facts, numbers, citations, technical terms, stance, and intended length. Do not invent achievements, sources, precision, causal claims, or quotes to make prose sound stronger. When changing meaning would help, suggest it separately.

**Research mode (中文 / English):** put the claim or question first, then method/evidence, then the limit or implication. Make the subject of each sentence clear; use consistent terms, dates, units, and comparison bases. Separate observed result from interpretation. Replace decorative transitions and vague intensifiers with concrete relations. In Chinese, prefer direct natural syntax over translated English abstractions; in English, prefer active verbs and readable sentence length.

**Literary mode (中文 / English):** preserve the idea and add rhythm, image, and voice only where they serve the reader. Vary sentence length intentionally; avoid stock metaphors, ornamental adjectives, false drama, and over-polished uniformity. Let the user's sample set the register if one is given. Never turn a research claim into a persuasive flourish that hides uncertainty.

For a rewrite, return the revised text first. Give brief notes only where a substantive change, unresolved ambiguity, or factual check matters. For a bilingual pair, write each language idiomatically; do not force a sentence-by-sentence calque. If the material is a document file, use the relevant document skill for layout and rendering.
