# 来源与因子卡

每条候选至少记录：

| 字段 | 要写清的内容 |
| --- | --- |
| source | 作者/机构、标题、日期、原始 URL、页码或源码行 |
| status | 公式准确、描述不完整、只有思路；访问限制 |
| formula | 数学式、方向、参数、单位、边界处理 |
| data | 所需字段、供应商、当时可获得时刻、修订和复权 |
| experiment | 股票池、样本期、调仓时刻、交易价格、标签、成本 |
| lineage | 数据哈希、代码版本、试验编号、与原文的差异 |
| verdict | 未测试、数据不足、被拒绝、待独立验证、已独立验证 |

可把多条候选存为 CSV，但详细公式和研报页码应保留到单独卡片。社区代码即使能跑，也要按上述字段核对；错误时点、偷看未来以及同义因子的重复命名很常见。
