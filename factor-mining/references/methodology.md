# 因子挖掘方法

## 路径与证据等级

先写经济机制，再选可观测代理变量，然后固定公式与时点，最后测试。常用来源：原始券商报告、论文、交易所披露、官方平台源码；社区贴仅作为线索。券商结论常依赖特定股票池、样本期、调仓和成本，迁移时必须重新检验。

每个实验保存数据快照哈希、获取时间、复权基准、股票池生成规则、代码版本、参数和所有试验结果。研报发表后的数据与发表前数据分开；不能用报告已研究的时期冒充独立验证。

## 有效时间线

`原始事件发生 → 对外发布 → 数据服务可见 → 信号计算 → 可成交时点 → 收益实现`。

财务报告使用实际披露日，不把报告期末当成已知日；若盘后披露，至少延后到下一可交易时点。分析师一致预期记录每条修订的时间。指数成分、ST、停牌和行业归类使用当时版本。复权行情可能随未来分红送转变化，回测中说明是否能重现当时屏幕所见。

## 筛选层次

1. **可实现性**：公式完整、字段合法、覆盖率、异常值、除零、滚动窗口起点。
2. **预测性**：分日 Rank IC 及其稳定性，分组收益与单调性；统一样本日期和股票池。小样本 IC 只算演示。
3. **独立性**：与简单动量、波动、市值、行业、流动性和已有候选的截面相关；必要时做中性化前后对照。
4. **可交易性**：次日价格、涨跌停和停牌、换手、费用、滑点、容量；长期只能做多时不以不可交易的多空收益作为主要结果。
5. **稳健性**：不同年份、行业、股票池、参数邻域和成本；按时间滚动训练与验证。每次看过验证集后，它就不再是盲测。

多重测试：完整记录搜索空间、未通过者和调参次数；预先确定核心指标与门槛。避免拿多个相关参数的最大 Sharpe/IC 当显著性证据。若正式声明显著性，使用与相关性和时间依赖匹配的多重比较或重采样方法，另留独立样本验证。参考 [Harvey, Liu, Zhu](https://www.nber.org/papers/w20592)；分组与换手分析可参考 [Alphalens](https://github.com/quantopian/alphalens)。

## 可复用来源

- [Qlib Alpha158 源码](https://github.com/microsoft/qlib/blob/main/qlib/contrib/data/loader.py)：具体公式以源码为准，变量与数据缺口要逐一核对。
- [Qlib 数据说明](https://github.com/microsoft/qlib/blob/main/docs/component/data.rst)：A 股标签示例把当日收盘信号的收益放在 T+1 到 T+2，避免同日收盘成交假设。
- [101 Formulaic Alphas](https://arxiv.org/abs/1601.00991)：可查明确表达式，但原论文市场、成本和频率不能直接搬到 A 股。
- [上交所实际披露日](https://www.sse.com.cn/disclosure/listedinfo/periodic/)：财报时点核验入口。

这些来源提供方法与候选，不保证未来有效。机器学习或自动公式搜索只在数据时点、验证和试验账本稳定后再加。
